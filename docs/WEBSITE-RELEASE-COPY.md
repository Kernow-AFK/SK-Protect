# Website copy — SK Protect v1.1.0-beta.1

## Release headline

### SK Protect now supports SKlauncher 4.0.57 beta

The SK Protect family has been updated for SKlauncher 4.0.57 on Linux x86_64. This beta brings SK Protect, SK Mod Installer, and SK Preferred Mods together in one guarded patch kit.

## Custom text colors

Some of SKlauncher's muted gray text was difficult to read in dark mode. SK Protect now adds **Custom text colors** under **Settings → Appearance**, where you can choose your own primary and secondary text colors. The launcher saves those choices locally. This is part of the combined SK Protect package rather than a separate color-picker download, so the color controls stay version-matched with the rest of the patch.

## What's in the SK Protect family

- **SK Protect:** reduces selected optional personal-data routes from the launcher. It is a focused launcher patch, not a firewall or a claim that every network connection is blocked.
- **SK Mod Installer:** keeps Content Hub available while an installation completes and lets you review several compatible instances together.
- **SK Preferred Mods:** save your usual mods, review what fits an instance, skip mods already installed, and optionally install enabled compatible mods automatically when each new instance is created.

Settings → About also shows the SK Protect release information and links to the project website and GitHub.

## Testing and compatibility

This is a beta for SKlauncher 4.0.57 on Linux x86_64. The maintainer's reported test machine is PC3 running Linux Mint 22.3; other operating systems have not been verified. The stable SKlauncher 3.2.18 line has not been ported. Accessibility, clean-profile, provider edge-case, network-comparison, and clean-environment rollback checks remain open. Please treat this as public testing, not a stable release.

## Get the source

Build your own patched copy from the official SKlauncher AppImage you obtain directly from its publisher. Keep the official original unchanged for rollback. SK Protect publishes source, documentation, and its own artwork; it does not distribute SKlauncher's AppImage or extracted launcher files.
