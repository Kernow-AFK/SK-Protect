# Licensing decision required

No `LICENSE` file is being added until the maintainer explicitly chooses terms and confirms ownership of the original scripts and artwork. Publicly visible source code is not automatically open-source licensed; without a licence, others generally have no permission to copy, modify, or redistribute it beyond applicable law.

## Option A: MIT

Short, familiar, permissive, and easy for contributors and directories to understand. It includes warranty and liability disclaimers. It does not include an express patent grant.

## Option B: Apache License 2.0

Permissive, but longer. It includes an express patent licence and patent-termination language, and requires preservation of notices and disclosure of modified files. This can be useful for a technically complex patch project, though it adds contributor/compliance detail.

Either licence should cover only the maintainer's original patch scripts, tests, documentation, and owned artwork/contributions. It cannot grant rights to SKlauncher's proprietary executable, source, trademarks, or assets; those are not distributed here. The final `LICENSE` and `NOTICE.md` should state that boundary clearly.
