# Security policy

## Supported version

Only the current SK Protect release for official SKlauncher 4.0.54 Linux x86_64 is supported. A newer upstream launcher is unsupported until the patch guards, behavior, and threat model are revalidated.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose account tokens, execute code, bypass a stated privacy control, corrupt instances, or cause unsafe file replacement. Email **Kernow-AFK@protonmail.com** with:

- the affected SK Protect version or commit;
- the patch mode;
- reproduction steps and impact;
- whether exploitation requires a modified launcher/AppImage;
- a minimal redacted log or proof of concept, if safe.

Do not send account credentials, access tokens, private server addresses, worlds, or proprietary SKlauncher files. No response-time guarantee is currently offered by this volunteer project.

SK Protect cannot provide security updates for SKlauncher itself. Users may always return to a fresh official, unpatched launcher while a compatible SK Protect release is being assessed.
