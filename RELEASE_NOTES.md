# SK Protect release notes

## v1.1.0 — SKlauncher 4.0.57 Open Beta

This release adds Custom text colors in Settings → Appearance and SK Protect version and project links in Settings → About. It also includes the SK Protect privacy controls, SK Mod Installer, and SK Preferred Mods, with instance-specific review and optional application of compatible preferred mods to new instances.

Download the source from [GitHub Releases](https://github.com/Kernow-AFK/SK-Protect/releases). Use it only with the exact SKlauncher version listed in the release. Obtain the original SKlauncher AppImage directly from its publisher; the original remains unchanged while SK Protect builds a separate patched copy.

## v1.0.0 — SKlauncher 4.0.54

The first combined SK Protect patch for the official SKlauncher 4.0.54 Linux x86_64 AppImage. It includes privacy controls, the multi-instance mod installer, and Preferred Mods.
