# Changelog

## v1.1.0 — SKlauncher 4.0.57 Open Beta

- Add Custom text colors in Settings → Appearance, with separate primary and secondary colors saved locally.
- Add SK Protect release information and project links in Settings → About.
- Refresh the Preferred Mods page with SK Protect branding, project artwork, and clearer controls.
- Add instance-specific Preferred Mods review, compatibility-aware release selection, and installed-mod skipping.
- Add optional installation of enabled compatible Preferred Mods when a new instance is created.
- Keep Content Hub open after a mod installation and support reviewing several instances together.
- Retain separate privacy-only, workflow, Preferred Mods, and combined build modes.

## v1.0.0 — SKlauncher 4.0.54

- Add SK Protect privacy controls for selected optional launcher behavior and routes.
- Keep Content Hub open after installation and add a multi-instance mod installer.
- Add a reusable Preferred Mods list and per-instance review.
